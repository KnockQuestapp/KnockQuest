# Branch Naming Standard

## Goals

- Keep branch history easy to audit.
- Make release intent clear for stakeholders and investors.

## Format

`<type>/<scope>-<short-description>`

Types:

- `feature`
- `fix`
- `chore`
- `docs`
- `hotfix`

Rules:

- Lowercase only
- Use hyphens for separators
- Keep under 50 characters if possible

Examples:

- `feature/migration-flutterflow-parity`
- `fix/login-session-timeout`
- `chore/ci-flutter-analysis-tests`
- `docs/security-policy-hardening`
