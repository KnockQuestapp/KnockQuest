Google Maps setup needed

This map is now built for Google Maps, but Google requires a browser API key for the Maps JavaScript API.

Create a restricted Google Maps key for knockquestapp.github.io/KnockQuest/*, enable Maps JavaScript API, then add it as window.KNOCKQUEST_GOOGLE_MAPS_API_KEY in google-maps-env.js.

Google offers free monthly usage tiers, but production Google Maps is still an API based service.
