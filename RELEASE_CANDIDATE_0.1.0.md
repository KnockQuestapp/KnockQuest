# Release Candidate: 0.1.0

## Suggested Tag

`v0.1.0`

## Release Title

`KnockQuest 0.1.0 - Migration Baseline`

## Summary

This release establishes the source-controlled migration baseline from FlutterFlow to Flutter, with investor-readable delivery practices and CI checks.

## Highlights

- Flutter app baseline initialized and validated.
- OSM map provider enabled for MVP cost control.
- Google Maps path preserved through configuration toggles.
- Descriptive commit and collaboration standards documented.
- Security and credential-protection safeguards added.

## Validation Checklist

- [x] `flutter test`

3. Set repository collaborator roles and enforce branch protections.
